# One (customer app)

Marketplace across every Devstrike product: search, listing detail, and "Continue on <product>", which
hands the person to the product's own booking page (the listing's primary action). One ID sign-in is
optional; settings hold the theme choice.

Routes (`go_router`): `/` splash, `/welcome` onboarding (once), `/discover` search, `/discover/listing/:id`,
`/you` account and settings, `/sign-in`.

See the workspace README for running, flavours and One ID client registration.
