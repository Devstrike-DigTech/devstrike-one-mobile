# one_ui

The **Devstrike One: Aso-oke** design system for Flutter: woven strip-cloth structure, indigo-black ink on
cotton paper, kola (warm) and river (cool) accents, brass for premium.

- `lib/src/tokens/one_tokens.g.dart` is generated by `tool/sync_tokens.dart` from the TypeScript
  design-tokens package; `tokens/tokens.json` is the snapshot it was built from. Do not edit either by hand.
- `OneTheme.light()` / `OneTheme.dark()`; `context.onePalette` and `context.oneText` expose the roles
  Material has no slot for (washes, brass, weave, eyebrow and numeric styles).
- Fonts: Newsreader (display), Public Sans (UI), Martian Mono (numbers, tabular) via `google_fonts`.
- Icons: `OneIcons`, a curated Phosphor 2.1 set with the font files vendored in `fonts/` (MIT).
- Motif: `WovenBand` / `WovenBandPainter`. Thin and structural: a rule under headings, a band on splash and
  empty states, never a fill behind text.
- Components: `OneButton`, `OneTextField`, `OneCard`, `OneTag`, `OneSectionHeader`, `ListingTile`,
  `ListingThumbnail`, `OneEmptyState`, `OneErrorState`, `OneLoadingState`, `OneWordmark`.

Tests: `flutter test` (widget, contrast and golden tests). Re-record goldens with
`flutter test --update-goldens` after a deliberate visual change or a token sync, and review the PNGs in
`test/goldens/` before committing. Other packages call `setUpOneUiForTests()` from
`package:one_ui/one_ui_testing.dart` in their `flutter_test_config.dart`.
